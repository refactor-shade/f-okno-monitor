# F-OKNO Slot Monitor (Telegram Bot)

Telegram-бот для мониторинга сайта **f-okno.ru**.  
Он автоматически проверяет появление свободных слотов на передачу в СИЗО и присылает уведомление в Telegram.

Проект создан, чтобы **не обновлять страницу вручную** и не пропускать свободные даты.

---

## 🔍 Как это работает

- GitHub Actions запускается **примерно раз в 5–10 минут** (возможны небольшие задержки)
- Selenium открывает страницу нужного СИЗО
- Проверяется наличие текста **«Есть места»**
- Если появились новые свободные даты → приходит сообщение в Telegram
- Если изменений нет → бот молчит

Бот **не спамит** и пишет только при появлении свободных слотов.

## 🧰 Что нужно

- Аккаунт на **f-okno.ru**
- GitHub-аккаунт
- Telegram
- 15–20 минут на настройку

Никаких серверов и хостинга не требуется.

## 🤖 Шаг 1. Создать Telegram-бота

1. Откройте в Telegram: **@BotFather**
2. Напишите `/start`, затем `/newbot`
3. Задайте имя и username бота
4. Скопируйте **BOT TOKEN** — он понадобится дальше

---

## 💬 Шаг 2. Узнать TELEGRAM_CHAT_ID

### Если хотите, чтобы бот писал **вам лично**

1. Напишите боту любое сообщение
2. Откройте в браузере:
   https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/getUpdates
3. В ответе найдите:
   "chat": { "id": 123456789 }
4. Это и есть `TELEGRAM_CHAT_ID`

### Если хотите, чтобы бот писал **в отдельный чат/группу**

1. Создайте чат/группу
2. Добавьте бота в группу
3. Напишите любое сообщение в группу
4. Откройте в браузере:
   https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/getUpdates
5. В ответе найдите:
   "chat": { "id": -1001234567890 }
   `chat.id` для групп/каналов часто бывает **отрицательным числом**

## 🍴 Шаг 3. Форк репозитория

1. Нажмите кнопку **Fork** в правом верхнем углу репозитория
2. Создайте копию репозитория в своём GitHub-аккаунте

После этого все изменения вы будете делать уже в своём репозитории.

---

## 🔐 Шаг 4. Добавить Secrets в GitHub

Откройте в своём репозитории:

Settings → Secrets and variables → Actions → New repository secret

Добавьте следующие secrets:

- TELEGRAM_BOT_TOKEN — токен, полученный у @BotFather
- TELEGRAM_CHAT_ID — chat_id (пользователь, группа или канал)
- F_OKNO_EMAIL — email (логин) от аккаунта на f-okno.ru
- F_OKNO_PASSWORD — пароль от аккаунта на f-okno.ru

⚠️ Эти данные **никогда не должны попадать в код**.  
⚠️ Если вы меняете пароль на f-okno.ru — обновите `F_OKNO_PASSWORD` в Secrets.

---

## 🔗 Шаг 5. Указать нужное СИЗО

Откройте файл:

.github/workflows/monitor.yml

Найдите блок `env:` и укажите нужные ссылки:

TARGET_URL: "https://f-okno.ru/base/moscovskaya_oblast/sizo11noginsk"  
LOGIN_URL: "https://f-okno.ru/login?request_uri=%2Fbase%2Fmoscovskaya_oblast%2Fsizo11noginsk"

⚠️ Важно:
- В примере представлены ссылки для **СИЗО-11 (Ногинск)**.
- Вы можете заменить ссылки на любое другое СИЗО с сайта f-okno.ru (важно, чтобы `LOGIN_URL` соответствовал `TARGET_URL`).

Подсказка:
- TARGET_URL — это адрес страницы СИЗО вида: https://f-okno.ru/base/...
- LOGIN_URL — это адрес логина, где request_uri соответствует пути из TARGET_URL

Пример:
Если TARGET_URL содержит `/base/moscow/si12zelenograd`,  
то LOGIN_URL должен быть:
https://f-okno.ru/login?request_uri=%2Fbase%2Fmoscow%2Fsi12zelenograd

---

## ▶️ Шаг 6. Запустить бота

1. Перейдите во вкладку **Actions**
2. Выберите workflow **Monitor SIZO-11 slots**
3. Нажмите **Run workflow**

Если всё настроено правильно, бот начнёт работу сразу после запуска.
Если бот выдал ошибку – отправьте баг в любой AI-assistant и попросите помочь.

## 🕒 Настройка частоты проверок

Откройте файл `.github/workflows/monitor.yml` и найдите строку с `cron`, например:

cron: "*/7 * * * *"

Это означает запуск **раз в 7 минут** (по UTC).  
Можно изменить значение на любое подходящее вам.

Примеры:

- каждые 5 минут: `*/5 * * * *`
- каждые 10 минут со смещением на 5 минут: `5-59/10 * * * *`

---

## ⚠️ Важно знать

- GitHub Actions не является realtime-сервисом: возможна задержка запуска (обычно 1–2 минуты, иногда — до нескольких часов)
- При большой нагрузке на GitHub возможны очереди (`Queued`) и более длинные интервалы
- Верстка сайта f-okno.ru может измениться — тогда потребуется обновить парсер
- Используйте бота ответственно и не создавайте чрезмерную нагрузку на сайт
